## 后续迁移原则

- 先迁移纯逻辑和测试，再连接 Electron/React。
- 每个阶段保持独立可运行，不把 Codex 作为运行依赖。
- 宠物同步坚持“校验后复制”，不直接从 Codex 目录长期运行。
- 同 ID、同内容跳过；同 ID、不同内容报告冲突，不静默覆盖。
- 正式发布缺少签名、版本、产物或校验和时失败关闭。
